👑 Gérer les accès — maquette T4b (Admin invité)

Tu es Phiphi, Administratrice du dossier « Voyage eclipse » (tu l'as créé → admin de naissance). Clique « Gérer les accès » dans le bandeau → tu nommes les invités de ton lien, dans ton sous-arbre, jusqu'à Administrateur « comme toi ». Clique une pastille de rôle pour voir le popover. L'owner n'apparaît jamais, tu ne peux pas te changer toi-même, et chaque acte le notifie (révocable). Tout est en mémoire.

Ce que la maquette fige : ① le bouton « Gérer les accès » n'apparaît que pour un Admin ; ② le panneau ne montre que les invités du lien dans le sous-arbre de l'Admin (l'owner absent, soi-même verrouillé) ; ③ le popover de rôle est borné à Administrateur (pas de rôle au-dessus, pas « owner ») et rappelle « borné à ton sous-arbre · l'owner sera notifié » ; ④ l'Admin reçoit aussi les demandes de rôle de son sous-arbre (accord 1 clic) ; ⑤ pas d'approbation préalable : l'acte part, l'owner est notifié et peut révoquer ; ⑥ centré desktop / bottom-sheet mobile, comme le reste.
