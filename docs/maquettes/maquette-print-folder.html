⭐ Top 20 kanji à retenir avant le 1er nov. (révision express)

📅 sam. 31 oct.  ·  📁 🈷️ Kanji utiles  ·  P3

Si tu n'en retiens que 20, retiens ceux-là. Les 4 autres mémos du dossier servent de dico sur place.

  1. 入口 entrée
  2. 出口 sortie
  3. 駅 gare
  4. 男 homme
  5. 女 femme
  6. 肉 viande
  7. 魚 poisson
  8. 牛 bœuf
  9. 豚 porc
  10. 鶏 poulet
  11. 水 eau
  12. 酒 alcool
  13. 円 yen
  14. 無料 gratuit
  15. 辛 épicé
  16. 押 pousser
  17. 引 tirer
  18. 開 ouvrir
  19. 閉 fermer
  20. 禁止 interdit

Moyens mnémotechniques :

  • 入 ressemble à quelqu'un qui entre sous un toit → entrée ; 出 = deux montagnes qui sortent du sol → sortie.
  • 男 = un champ 田 + la force 力 → l'homme aux champs ; 女 = silhouette qui danse → femme.
  • 牛 = tête de vache avec ses cornes ; 魚 = poisson vu de haut (tête, écailles, queue en 4 points).
  • 水 = eau qui éclabousse ; 辛 = aiguille qui pique → piquant.
  • 開 contient 开 (deux barres ouvertes) → ouvert ; 閉 contient 才 (une barre qui bloque) → fermé.
